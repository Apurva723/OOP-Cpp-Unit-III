Brief description of each program

1 - Function Overloading — Demonstrates compile-time polymorphism by using multiple functions with the same name but different parameters.

2 - Area Calculator — Calculates the area of a square, rectangle, and circle using overloaded functions with different parameters.

3 - Unary Minus Operator — Demonstrates overloading of the unary - operator to change a number into its negative value.

4 - Prefix and Postfix Increment — Demonstrates overloading of the ++ operator in both prefix and postfix forms.

5 - Complex Number Addition — Demonstrates binary + operator overloading to add two complex numbers.

6 - Distance Comparison — Demonstrates relational operator overloading using the > operator to compare two distances.

7 - Non-Member/Friend Operator — Demonstrates operator overloading using a friend function to access private data of a class.

8 - Base Pointer Without Virtual Function — Demonstrates static binding where a base-class pointer calls the base-class version of a function.

9 - Base Pointer With Virtual Function — Demonstrates runtime polymorphism using a virtual function and a base-class pointer.

10 - Base Reference With Virtual Function — Demonstrates dynamic binding by passing a derived object through a base-class reference.

11 - Abstract Class — Demonstrates a pure virtual function and shows how a derived class provides its implementation.

12 - Collection of Shape Pointers — Stores different shape objects using pointers and processes them polymorphically to display their names and areas.

13 - Virtual Destructor — Demonstrates how a virtual destructor safely destroys a derived object through a base-class pointer.

14 - Object Slicing — Demonstrates how passing a derived object by value to a base-class parameter removes the derived-class information.

15 - Payment System — Demonstrates an abstract payment interface with different payment methods such as card, UPI, and net banking.

16 - Payroll Mini-Project — Demonstrates polymorphism in an employee payroll system for calculating salaries of permanent and contract employees.
